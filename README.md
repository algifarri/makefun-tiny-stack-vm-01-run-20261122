A faithful, compact interpreter for make.fun's tiny stack ISA v1: wrapping 32-bit arithmetic, a 256-value stack, calls, 256 words of memory, and all ten traps with their own exit codes — including the hard rules the house baseline skips (exact `Math.imul`, `INT_MIN / -1`, unsigned `DIVU`/`MODU`/`LTU`, 5-bit shift masks, `PUSH8` sign extension, step/output limits).
